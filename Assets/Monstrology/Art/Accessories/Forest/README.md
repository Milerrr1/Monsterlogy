# Forest Set

Финальные спрайты лесного комплекта:

- `ForestHat.png` -> `forest_hat` -> `HeadAnchor`
- `ForestScarf.png` -> `forest_scarf` -> `BodyAnchor`
- `ForestBoots.png` -> `forest_boots` -> `LegAnchor`

Все три предмета входят в `forest_set`, выпадают только в `Forest` и используют
`bread_cat` как сигнатурный вид. Положение и размер задаются через
`AccessoryData.visualOffset` и `visualScale` поверх стандартных якорей
`CreatureBaseTemplate`.

Повторяемая установка:

`Tools > Monstrology > Install Forest Content`

Проверка:

`Tools > Monstrology > Validate Forest Content`
